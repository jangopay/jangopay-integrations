# Brand and publication assets

Use the included original JangoPay brand images. `assets/images/jangopay-icon.png` and `jangopay-wordmark.png` are local runtime files. Classic checkout bounds its icon to 28 × 28 pixels; Blocks provides a decorative icon with a persistent text label and hides a failed image without hiding the label.

Existing merchant titles, descriptions and intentionally empty values are retained. Defaults are configured in the gateway form fields and the Blocks data provider; the payment gateway ID remains `jangopay_woocommerce`.

The directory-assets ZIP is separate. Upload its `assets/` folder to the top level of the WordPress.org SVN repository beside `trunk/`, not inside the install ZIP. It contains square PNG icons, an SVG with the original brand image embedded, normal/retina banners and three actual local-test-site screenshots. Screenshots demonstrate interface only, not a real payment. Match screenshot numbering to `readme.txt`.

Product page: https://wordpress.org/plugins/jangopay-for-woocommerce/

Use the official product description, README and branded WooCommerce settings for plugin information. Keep contributor details, brand assets and policy links current. JangoPay branding identifies the service and does not imply WordPress or WooCommerce endorsement.
