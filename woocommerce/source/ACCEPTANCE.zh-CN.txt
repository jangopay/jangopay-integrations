JangoPay for WooCommerce 1.0.2 — 交付与升级说明

一、交付文件
安装包用于 WordPress 后台安装；完整开发源码包用于源码查阅、维护与重建。安装包与完整源码包分开提供，校验值见 woocommerce/SHA256SUMS.txt。

二、版本与依赖
插件版本头、JPWC_VERSION、Stable tag 为 1.0.2。
运行依赖：私有命名空间的 phpseclib 4.0.2、constant_time_encoding v3.1.3、polyfill-php82 v1.43.0。
RSA 使用 JangoPayWooVendor\phpseclib4，OAEP 与 MGF1 为 SHA-256，AES-GCM 由 PHP OpenSSL 处理。

三、构建
运行时 PHP >=8.1，锁定的构建工具 PHP >=8.4.1。
原始 Composer 锁文件和可重建脚本位于 build/ 与 upgrade/phpseclib4/，步骤见 BUILD.md。
安装包附带运行依赖与许可证；安装时不需要商户服务器运行 Composer。

四、升级与操作
升级前备份数据库、插件文件和支付台账。
沿用服务端 API Key 配置与网站公开目录之外的私钥路径，不覆盖仍在使用的密钥。
只启用一份 JangoPay 插件。保持 HTTPS，配置账户已启用的资产网络、公钥与回调地址。
付款通过商户 API 核验后进入 WooCommerce 订单处理；浏览器回跳不作为付款凭证。
保留不确定的支付记录，使用重新核验与只读恢复处理异常，不删除台账来强制重复创建发票。
手动 WooCommerce 退款不自动退回数字货币。

五、产品入口
WordPress.org：https://wordpress.org/plugins/jangopay-for-woocommerce/
官网：https://www.jangopay.org/
开发文档：https://doc.jangopay.org/documentation
